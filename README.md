# Journal calories

Journal de calories en appli web installable (PWA) : repas, activités, recettes, poids avec courbe, plusieurs profils, thèmes personnalisables.

- **Données** : enregistrées dans ton navigateur (localStorage). Export/import d'une sauvegarde dans Réglages.
- **Estimation par Claude** (facultatif) : colle ta clé API Anthropic dans Réglages. Elle reste sur ton appareil et n'est envoyée qu'à api.anthropic.com. Sans clé, tu ajoutes les lignes à la main.
- **Hors ligne** : après la première ouverture, l'appli fonctionne sans connexion.

## Installer sur téléphone
Ouvre l'adresse de l'appli dans Chrome (Android) ou Safari (iPhone), puis « Installer l'application » / « Sur l'écran d'accueil ».
